# 西华大学校园网自动登录 CampusLogin

一个给自己用的校园网自动登录小工具：连上 **XHU-WLAN** 后自动完成锐捷 ePortal 网页认证，掉线自动重连。

- 图形界面在浏览器里打开，不用记命令
- 账号密码保存在本机（Windows 凭据管理器 / macOS 钥匙串），不联网上传
- 支持开机自启，登录系统后在后台默默续命
- 提供 macOS（Apple Silicon）与 Windows 打包版，开箱即用，不需要装 Python

> 仅适用于 **ePortal Web 认证**，不支持 802.1X / PPPoE / DR.COM 等其他认证方式。
> 本项目与学校、运营商无关，仅供学习交流，请遵守校园网使用规定。

## 一、下载

到 [Releases](../../releases) 页面下载对应文件：

| 平台                                | 文件                          | 说明                            |
| ----------------------------------- | ----------------------------- | ------------------------------- |
| macOS（Apple Silicon，M1/M2/M3/M4） | `CampusLogin-macos-arm64.zip` | 解压后得到 `CampusLogin.app`    |
| Windows 10 / 11（64 位）            | `CampusLogin-win-x64.exe`       | 直接双击运行 |

> 程序未做代码签名，首次运行会被系统拦一次，按下面的步骤放行即可，属正常现象。

---

## 二、macOS 使用

1. 双击 zip 解压，把 `CampusLogin.app` 拖进「应用程序」文件夹。

2. 第一次打开：**右键点图标 → 打开 → 弹窗里再点「打开」**。
   之后就可以直接双击了。

3. 如果提示「已阻止 CampusLogin」：
   系统设置 → 隐私与安全性 → 找到 CampusLogin → 点「仍要打开」。

4. 如果提示「已损坏，无法打开」（多见于用第三方解压工具）：

   ```bash
   xattr -cr /Applications/CampusLogin.app
   open /Applications/CampusLogin.app
   ```

运行时会自动打开浏览器界面；关掉浏览器**不会**停止后台登录。

---

## 三、Windows 使用

1. 双击 `CampusLogin.exe`。
2. 若弹出 SmartScreen「Windows 已保护你的电脑」：
   点「更多信息」→「仍要运行」。
   个别杀毒软件可能误报 PyInstaller 打包的程序，加信任即可。

程序不会写注册表、不需要管理员权限，删掉文件夹就等于卸载。

---

## 四、首次配置

浏览器打开界面后：

1. 填 **校园网账号** 和 **密码**；
2. 「认证方式」一般选 **电信网**（默认），移动/联通/校内网按自己情况选；
3. 点 **保存配置**。保存成功后会自动开始认证。

状态徽标含义：

| 徽标         | 含义                           |
| ------------ | ------------------------------ |
| 🟢 在线       | 已联网，正在后台做心跳检查     |
| 🔵 认证中     | 正在获取认证页 / 提交登录      |
| 🟡 未连校园网 | 没连上 XHU-WLAN，或还没拿到 IP |
| 🔴 认证失败   | 账号密码错误、服务编号不对等   |

其他按钮：

- **立即登录**：不等下一个检查周期，马上检查一次；
- **停止 / 开始**：暂停或恢复自动登录循环；
- **高级选项**：调整在线检查间隔（默认 30 秒）、失败重试间隔，选「自定义」时填服务编号；
- **清除已保存密码**：只清密码，不清账号；
- **退出程序**：真正退出。只关浏览器标签页不算退出。

> 密码框留空表示「不修改已保存的密码」。

## 五、开机自启

在界面里勾选 **开机自启** 即可，不需要额外脚本：

- Windows：在「启动」文件夹放一个快捷方式；
- macOS：写入 `~/Library/LaunchAgents/com.xhu.campuslogin.plist`，登录后在后台运行、不弹浏览器。

取消勾选就会移除。以后想手动打开界面，再双击一次程序即可（已在运行会直接打开现有界面）。

## 六、数据与隐私

| 内容                     | Windows 位置                               | macOS 位置                                              |
| ------------------------ | ------------------------------------------ | ------------------------------------------------------- |
| 账号、认证方式、检查间隔 | `%APPDATA%\CampusLogin\config.json`        | `~/Library/Application Support/CampusLogin/config.json` |
| 密码                     | Windows 凭据管理器（`CampusLogin/<账号>`） | 登录钥匙串                                              |
| 日志                     | `%APPDATA%\CampusLogin\app.log`            | 同目录 `app.log`                                        |
| 界面地址                 | `%APPDATA%\CampusLogin\ui-url.txt`         | 同目录 `ui-url.txt`                                     |

- 密码不会写进 `config.json`，也不会出现在日志里；
- 界面只监听 `127.0.0.1`，只有本机能访问，且需要带访问令牌的地址；
- 程序只和校园网认证服务器通信，没有其他上报。

## 七、常见问题

**浏览器没自动打开 / 提示 403**
地址里少了 token。从 `ui-url.txt` 里复制完整地址，或用开始菜单/启动台快捷方式打开。
这个地址是持久化的，可以收藏。

**提示端口被占用**
程序会自动依次尝试 8765–8774，`ui-url.txt` 里始终写着实际可用的地址。

**开机后没有自动登录，日志说「未获取到认证页」**
多半是还没连上 `XHU-WLAN`。让系统记住该 Wi-Fi 并开启自动连接，程序会按重试间隔一直尝试。

**刚登录就掉线**
关掉该 Wi-Fi 的「随机硬件地址 / 私有 Wi-Fi 地址」。门户按 MAC 绑定会话，随机 MAC 会让认证立即失效。

**换了电脑 / 移动了程序目录后自启失效**
重新勾选一次「开机自启」即可。

**想彻底删除**

1. 取消勾选「开机自启」；
2. 删除上面表格中的数据目录；
3. Windows 再到「凭据管理器 → Windows 凭据」删除 `CampusLogin/<账号>`；
4. 删除程序文件夹。
